# accel_map.csv / brake_map.csv について

`raw_vehicle_cmd_converter` が目標加速度 [m/s²] からスロットル比 / ブレーキ比 (0..1) を逆引きする表。
行 = ペダル比、列 = 速度 [m/s]。行 0.0 は「ペダル無し（コースト）」で、両マップで同一。
目標加速度が行 0.0 の値を下回るとブレーキ側に切り替わる。

同じ値を `aichallenge_awsim_adapter/data/` にも置いてある。あちらはシミュレータ向けに
ペダル比 → 加速度の順変換として使うので、両者を揃えておくと sim と実車で挙動が一致する。

## 構成式

- `coast(v) = −0.40 − 0.03·v`
- `accel_map(u, v) = coast(v) + u^0.75 · (a_full(v) − coast(v))`
  - `a_full` = 全開時の加速度: 0 m/s +0.50、2 m/s +0.91、4 m/s +0.87、6 m/s +0.79、8 m/s +0.70、10 m/s +0.68
  - 指数 0.75 は中間スロットル域の形状を与えるパラメータで、0.1〜0.7 行はこの補間
- `brake_map(u, v) = coast(v) + Δa_brake(u)`
  - `Δa_brake` = 0.1: −0.05、0.2: −0.10、0.3: −0.15、0.4: −0.20、0.5: −0.50、0.6: −1.50、0.7: −2.50、0.8: −3.50、0.9: −4.50、1.0: −5.50
  - ブレーキは「不感帯 + 急峻」の非線形（不感帯 ≈ 0.45、勾配 ≈ 10 m/s²/ratio）。
    0.1〜0.4 の微小勾配は Autoware `CSVLoader::validateMap` の狭義単調性を満たすためのもの

## 既知の限界

- ブレーキの効き始めは車両差が大きく、この 1 枚では全車に合わない。車両別の較正
  （または車両別マップ切替）が必要。
- 中間スロットル行は補間値。0 m/s 列は発進帯 (0.3〜1.0 m/s) の値。

# accel_map.csv / brake_map.csv について

`raw_vehicle_cmd_converter` が目標加速度 [m/s²] からスロットル比 / ブレーキ比 (0..1) を逆引きする表。
行 = ペダル比、列 = 速度 [m/s]。行 0.0 は「ペダル無し（コースト）」で、両マップで同一。
目標加速度が行 0.0 の値を下回るとブレーキ側に切り替わる。

## 出典

- **データ**: 2026-06-02 の実車 rosbag（50 Hz）、3 車両 4 セッション（RK-03 / RK-98 / RK-97×2、計約 48 分、最高 11.5 m/s）。
  ペダル比は `/vehicle/status/actuation_status`（VCU スロットル開度、ブレーキモータ実トルク）、
  速度は GNSS ドップラーで較正した VCU 速度、加速度はその微分に GNSS 勾配補正を加えたもの。
- **推定**: ペダル遅れ（accel 0.06 s / brake 0.12 s）を補正し、ペダルが ±0.35 s 変化していない直線走行サンプルの中央値。
  CI はセグメント単位ブートストラップ。

## 構成式

- `coast(v) = −0.40 − 0.03·v`（プール推定 c0 = 0.398、95% CI [0.369, 0.429]）
- `accel_map(u, v) = coast(v) + u^0.75 · (a_full(v) − coast(v))`
  - `a_full` = 全開時の実測加速度: 0 m/s +0.50、2 m/s +0.91、4 m/s +0.87、6 m/s +0.79、8 m/s +0.70、10 m/s +0.68
  - 指数 0.75 は唯一の中間実測点（ratio 0.8 で全開の 0.85 倍）に合わせた値。0.1〜0.7 行はこの補間
- `brake_map(u, v) = coast(v) + Δa_brake(u)`
  - `Δa_brake` = 0.1: −0.05、0.2: −0.10、0.3: −0.15、0.4: −0.20、0.5: −0.50、0.6: −1.50、0.7: −2.50、0.8: −3.50、0.9: −4.50、1.0: −5.50
  - ブレーキは「不感帯 + 急峻」の非線形で、不感帯の位置が車両ごとに違う（RK-03 / RK-97 ≈ 0.6、RK-98 ≈ 0.15、RK-25 ≈ 0.35）。
    上の値は 4 車両の中央値（不感帯 ≈ 0.45、勾配 ≈ 10 m/s²/ratio）。0.1〜0.4 の微小勾配は
    Autoware `CSVLoader::validateMap` の狭義単調性を満たすためのもの

## 既知の限界

- ブレーキは車両差が大きく、この 1 枚では全車に合わない。車両別の較正（または車両別マップ切替）が必要。
- 中間スロットル行は補間値。10 m/s 列は RK-97 の 1 セッションのみ。0 m/s 列は発進帯 (0.3〜1.0 m/s) の値。
- 6 月の 3 車両では Autoware の実運用ブレーキ上限 (≈0.64) で減速がほとんど生じていなかった。

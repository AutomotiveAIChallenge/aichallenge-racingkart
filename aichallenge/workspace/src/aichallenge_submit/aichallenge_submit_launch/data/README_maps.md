# accel_map.csv / brake_map.csv について

- **出典**: A3（`ECU-RK-02`）の実車テレメトリ（1Hz、2026-09-04〜09-11収録、`gear=D`のみ）から実測構築。
  推定は「指令が変化していない連続サンプル対の `dv/dt`」を平均速度でビン分けした中央値。
- **対象車両**: A3単独。他車（A2/A6/A7）および2025年のチームrosbagは**混ぜていない**。
- **accel_map**: ratio 0.0(コースト、n=69)・1.0(フルスロットル、n=517) が実測。
  0.1〜0.8は実運用が0/100の離散指令で中間データが無く、両端の線形補間値。
  0 m/s列は実際は0.8〜1.0 m/sの発進帯。
- **brake_map**: `brake_map(ratio,v) = coast(v) + Δa_brake(ratio)`。coast(v)はaccel_map行0.0と共通。
  Δa_brakeは9/4のブレーキ保持試験から推定した速度非依存の値で、ratio 0.2/0.4/0.6/0.8が実測
  (n=8/4/2/1、高ratioほど低信頼)。0.1/0.5は補間値。**ratio 1.0は実測が無く**、0.8までの傾向を
  そのまま延ばすと -6 m/s²超になるため、合成値が -5.0 m/s² で頭打ちになるよう Δa_brake=-4.50 とした。
- **速度列**: A3は7 m/s超の走行データが無いため、8/10 m/s列は6 m/sの値を保持。
- **単調性**: Autowareの `CSVLoader::validateMap` が要求する狭義単調性（accelは増加、brakeは減少）
  を満たすことを確認済み。

詳細（データ・手法・実測値・rosbagとの比較・限界・再現手順）は解析レポート
`reports/20260911-a3-accel-brake-map/report.md` を参照。

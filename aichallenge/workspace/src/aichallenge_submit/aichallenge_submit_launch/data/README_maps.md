# accel_map.csv / brake_map.csv について

- **出典**: 実車テレメトリ（1Hz VCU + 20Hz GNSS/V2X, 2026-09-04・09-10収録）から実測構築。
- **対象車両**: A2, A6, A7 をプールして推定。**A3は既知の外れ値車両のため除外**。
- **accel_map**: ratio 0.0(コースト)・0.8・1.0 は実測。0.1〜0.6は中間スロットルデータが
  ほぼ無く（実運用が0/80/100の離散指令）全て補間値。0 m/s列は実際は0.3〜1.0 m/sの発進帯。
- **brake_map（再構築版）**: `brake_map(ratio,v) = coast(v) + Δa_brake(ratio)`。coast(v)は
  accel_map行0.0と共通。Δa_brake は「ブレーキ保持イベント」（20Hz V2X速度への直線フィット、
  停止直前の非線形域を除外）23件から推定した**速度非依存**の値。ratio 0.2/0.4/0.6/1.0は
  実測イベントあり（n=3〜10、低信頼含む）。0.1/0.5/0.8は補間値。full-brake(1.0)は生の
  イベント中央値(-4.51)を物理的妥当性の上限(合成後 -4.5 m/s²)に収めるため -3.92 に調整済み。
- **単調性**: Autowareの `CSVLoader::validateMap` が要求する狭義単調性を満たすよう補正済み。
- **検証**: accelはheld-out 30%分割、brakeはleave-one-event-out交差検証で逆引き残差を確認。
  どちらも現行マップよりばらつきが小さい。

詳細（データ・手法・全イベント一覧・ソースフラグ・検証結果・限界・再現手順）は
運営側の解析レポート `a3-acceleration-telemetry-20260910/maps/README.md` を参照。

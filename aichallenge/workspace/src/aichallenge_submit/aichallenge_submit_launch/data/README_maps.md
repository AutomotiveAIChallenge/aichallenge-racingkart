# accel_map.csv / brake_map.csv について

`raw_vehicle_cmd_converter` が目標加速度 [m/s²] からスロットル比 / ブレーキ比 (0..1) を逆引きする表。
行 = ペダル比、列 = 速度 [m/s]。行 0.0 は「ペダル無し（コースト）」で、両マップで同一 (−0.5 m/s²)。
目標加速度が行 0.0 の値を下回るとブレーキ側に切り替わる。

同じ値を `aichallenge_awsim_adapter/data/` にも置いてある。あちらはシミュレータ向けに
ペダル比 → 加速度の順変換として使うので、両者を揃えておくと sim と実車で挙動が一致する。

## brake_map.csv

実機確認済みの値をそのまま維持している。ブレーキは不感帯の後に急峻に効く非線形で、
0.6 (−2.5) から 0.8 (−13.3)、1.0 (−34.0) と立ち上がる。

## accel_map.csv

従来の形状をそのまま維持し、行 0.0（コースト）のみ brake_map.csv と揃えて
−0.3 → −0.5 に修正した。両マップの行 0.0 が一致していないと、その間の目標加速度帯が
どちらのマップにも載らず、アクセル／ブレーキ切り替え点で不連続が生じるため。

## 既知の限界

- ブレーキの効き始めは車両差が大きく、この 1 枚では全車に合わない。車両別の較正
  （または車両別マップ切替）が必要。
